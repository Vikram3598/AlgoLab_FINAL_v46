How: enqueue the start node; while the queue is not empty, dequeue the front, mark it visited, and enqueue all undiscovered neighbors. Nodes leave the queue in non-decreasing distance order → BFS finds shortest paths in unweighted graphs. Time: O(V+E) | Space: O(V) | structure: FIFO queue

Mark nodes discovered when pushed to avoid duplicates; when a node has no new neighbors, it is exhausted → backtrack. Time: O(V+E) | Space: O(V) | structure: LIFO stack
