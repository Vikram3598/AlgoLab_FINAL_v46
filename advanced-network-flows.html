How: minimum vertex cover is NP-hard, so take every edge in order; if it is not yet covered, add both of its endpoints. Each addition is charged to a vertex an optimal cover would need anyway ⇒ |greedy| ≤ 2 · OPT - a 2-approximation in one linear pass. Brute force over all 2ⁿ subsets supplies the true OPT for comparison. Time: O(E + 2ⁿ · n) for OPT check | guarantee: ratio ≤ 2

How: every round, score each set by how many still-uncovered elements it would add and take the best (ties break by index). The classic trap set S3 grabs 4 elements first but forces a third set - greedy returns 3 where OPT needs only 2. Analysis bounds greedy ≤ H(n) · OPT (H(6) ≈ 2.45), the best poly-time ratio unless P = NP. Time: O(n · m) | guarantee: ratio ≤ H(n) ≈ ln n
