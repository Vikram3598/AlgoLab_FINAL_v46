Dijkstra's Algorithm

Find shortest paths from source node 0 to all other nodes

Press Play or Step to begin
0.8s
How it works: Start from source node 0. Repeatedly pick the unvisited node with the smallest tentative distance, mark it visited, and update neighbors if a shorter path is found.
Time: O((V+E) log V) | Space: O(V)

Prim's Algorithm

Grow a Minimum Spanning Tree from vertex 0

Press Play or Step to begin
0.8s
How it works: Start at vertex 0. At each step, add the cheapest edge connecting a visited vertex to an unvisited vertex. Repeat until all vertices are in the tree.
Time: O(E log V) | Space: O(V)

Kruskal's Algorithm

Build MST by adding cheapest edges that don't form cycles

Press Play or Step to begin
0.7s
How it works: Sort all edges by weight. Pick edges in order; add if it connects two different sets (no cycle). Use DSU to check connectivity. Stop when V-1 edges are added.
Time: O(E log E) | Space: O(V)

Huffman Coding

Build optimal prefix-free codes from character frequencies

Press Play or Step to begin
0.9s
How it works: Count character frequencies. Repeatedly merge the two lowest-frequency nodes. Left branch = 0, right = 1. Most frequent characters get the shortest codes.
Time: O(n log n) | Space: O(n)

Fractional Knapsack

Maximize value by taking items greedily by value/weight ratio

How it works: Sort items by value/weight ratio (greediest first). Take whole items until capacity is full. If the next item doesn't fit, take a fraction of it.
Time: O(n log n) | Space: O(1)
