N-Queens Problem

Place N queens so no two attack each other

Press Play or Step to begin
0.5s
How: Place queens column by column. If a queen conflicts (row/diagonal attack), backtrack and try the next row. When all N queens are placed, a solution is found. Time: O(N!) | Space: O(N)

Rat in a Maze

Find a path from start to end avoiding walls

Press Play or Step to begin
0.4s
How: Try moving right/down from each cell. Mark visited, recurse. If stuck (all neighbors blocked/visited), backtrack (unmark) and try another direction. Time: O(4^(N²)) | Space: O(N²)

Sudoku Solver

Fill 9×9 grid satisfying all constraints

Press Play or Step to begin
0.2s
How: Find the next empty cell. Try digits 1-9 that don't violate row/column/box constraints. If valid, place and recurse. If no digit works, backtrack. Time: O(9^(N²)) | Space: O(N²)

Graph Coloring (m-Coloring)

Color vertices so no adjacent vertices share a color

Press Play or Step to begin
0.5s
How: Assign colors to vertices one by one. If a color conflicts with an adjacent vertex, try the next color. If no color works, backtrack to the previous vertex. Time: O(M^V) | Space: O(V)

Hamiltonian Cycle

Find a cycle visiting every vertex exactly once

Press Play or Step to begin
0.5s
How: Build a path vertex by vertex. At each step, add an unvisited neighbor. If no unvisited neighbor exists or can't return to start, backtrack. When all V vertices are in path and last connects to first, a cycle is found. Time: O(V!) | Space: O(V)

Subset Sum Problem

Find all subsets whose elements sum to the target

Press Play or Step to begin
0.6s
How: Build a binary decision tree — at each element, either include it or exclude it. If sum exceeds target, prune. If sum equals target, record the subset. Time: O(2ⁿ) | Space: O(n)
