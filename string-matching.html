How: LPS[i] = length of the longest proper prefix of P[0..i] that is also a suffix. During search a mismatch sets j = LPS[j-1] — the pattern slides forward over characters already known to match, and the text pointer only advances. Time: O(n+m) | Space: O(m)

Rabin-Karp Algorithm

Rolling polynomial hashes — fingerprint first, verify only on hits

How: Hash the pattern once. For each text window compute a rolling hash: h' = ((h − T[s]·dm-1)·d + T[s+m]) mod M. Hash mismatch → skip instantly. Hash match → verify characters (a spurious hit possible with small M — watch for it!). Time: O(n+m) expected | demo: d=10, M=90
