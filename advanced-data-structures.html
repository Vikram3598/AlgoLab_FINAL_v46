AVL Tree Rotations

Balanced (bf 0/±1)New nodeImbalanced (bf ±2)Rotating / fixedRotation axis
Press Play or Step to begin

How: Insert like a normal BST, then walk back up updating heights. Balance factor = height(left) − height(right). If any node reaches ±2, the offending subtree rotates: LL→right, RR→left, LR→left-then-right, RL→right-then-left. The whole tree stays |bf| ≤ 1 → O(log n) guaranteed. Time: O(log n) per insert | Space: O(n)

How: New nodes insert RED. If parent is also red, fix: Case 1 — uncle red → recolor parent & uncle black, grandparent red, move up. Case 2/3 — uncle black → rotate (zig-zig / zig-zag) + recolor. Root is always black. Keeps search O(log n). Time: O(log n) per insert | Space: O(n)

How: Find(x) walks parent pointers to the root — with path compression, every node on the path is re-pointed DIRECTLY to the root (chains become stars). Union(a,b) attaches the shallower-rank root under the deeper one. Nearly O(1) amortized per operation. Time: ~O(α(n)) amortized | Space: O(n)

Segment tree: binary tree of ranges — queries descend, taking fully-covered nodes (green), skipping disjoint ones (red). Fenwick: each index i owns a power-of-two range; walks use i += lsb(i) (update) / i −= lsb(i) (prefix). Both do point-update + range-sum in O(log n). Time: O(log n) update & query | Space: O(n)
